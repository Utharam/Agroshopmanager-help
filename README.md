# 🌱 Agro Shop Manager — Documentation & User Guide

A standalone, responsive, bilingual (English & മലയാളം) static documentation website for **Agro Shop Manager**.

🌐 **Live Documentation Site**: [https://utharam.github.io/Agroshopmanager-help/](https://utharam.github.io/Agroshopmanager-help/)

---

## 🚀 GitHub Pages Deployment

This repository is configured with GitHub Actions to automatically deploy to GitHub Pages on every push to the `main` branch.

### Enabling GitHub Pages in Repository Settings:
1. Open [Agroshopmanager-help Settings](https://github.com/Utharam/Agroshopmanager-help/settings/pages).
2. Under **Build and deployment** ➔ **Source**:
   - Select **GitHub Actions** (or select **Deploy from a branch** ➔ `main` ➔ `/(root)`).
3. The site will be live at:
   **[https://utharam.github.io/Agroshopmanager-help/](https://utharam.github.io/Agroshopmanager-help/)** 🎉

## ✨ Features Included
- **🌐 Instant Bilingual Toggle**: Switch between *Show Both*, *English Only*, and *മലയാളം (Malayalam) Only*.
- **🔍 Instant Live Search**: Filter topics, GST rules, RCM guides, and shortcuts in real-time.
- **📱 Fully Mobile Responsive**: Fixed sticky sidebar with smooth scroll on desktop, collapsible drawer on mobile.
- **⚡ 100% Free & Fast**: Zero Netlify quota consumption with free bandwidth on GitHub Pages.
