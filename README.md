# 🌱 Agro Shop Manager — Documentation & User Guide

A standalone, responsive, bilingual (English & മലയാളം) static documentation website for **Agro Shop Manager**.

---

## 🚀 1-Click Deployment to GitHub Pages

1. Create a new GitHub repository named **`agro-shop-docs`** (or **`agro-shop-help`**).
2. Upload / push these files (`index.html` and `README.md`) to your new repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Agro Shop Manager documentation"
   git branch -M main
   git remote add origin https://github.com/<your-username>/agro-shop-docs.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** ➔ **Pages** (in the left sidebar).
   - Under **Build and deployment** ➔ **Source**, select **Deploy from a branch**.
   - Choose **`main`** branch and **`/(root)`** folder.
   - Click **Save**.
4. Your documentation site will go live at:
   **`https://<your-username>.github.io/agro-shop-docs/`** 🎉

## ✨ Features Included
- **🌐 Instant Bilingual Toggle**: Switch between *Show Both*, *English Only*, and *മലയാളം (Malayalam) Only*.
- **🔍 Instant Live Search**: Filter topics, GST rules, RCM guides, and shortcuts in real-time.
- **📱 Fully Mobile Responsive**: Fixed sticky sidebar with smooth scroll on desktop, collapsible drawer on mobile.
- **⚡ 100% Free & Fast**: Zero Netlify quota consumption with 100 GB/month free bandwidth on GitHub Pages.
